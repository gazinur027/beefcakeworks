5. ФОРМА ЗАЯВКИ — КАК УСТРОЕНА (ВАЖНО!)
---------------------------------------------------------------------
Имя формы: repair-request
Поля: fullName*, phone*, email*, streetAddress*, applianceType*
(список техники), problemDescription*, insuranceCompany
(список-заглушка: None/State Farm/Allstate/Geico/USAA/Other),
preferredDate (опционально, MM/DD/YYYY).

Ключевые механики:
  - Ключи payload ОБЯЗАНЫ точно совпадать с name в HTML — Netlify
    по ним сопоставляет поля. Рассинхрон = пустые заявки.
    Покрывается npm test (test-form-fields-match.mjs).
  - Отправка: POST / с form-name + URL-encoded телом
    (JSON Netlify не умеет).
  - Кириллица в name/address/description автоматически
    транслитится в латиницу при вводе (lib/translit.ts) — защита
    от заявок «по-русски».
  - Дата — текстовое поле с умной маской MM/DD/YYYY (не type=date:
    нативный плейсхолдер рендерится на языке ОС и не
    переопределяется).
  - Honeypot bot-field от ботов; кнопка блокируется при отправке.
  - На localhost отправка СИМУЛИРУЕТСЯ (Netlify Forms есть только
    на залитом сайте) — показывается success без сети.
  - После успеха — inline экран Thank you (плюс отдельная страница
    /thank-you как fallback для отправки без JS и URL конверсии
    для рекламы).
